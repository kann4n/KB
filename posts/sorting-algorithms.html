Sorting Algorithms

Introduction

Sorting algorithms are used to arrange elements in a specific order. This post covers the most common sorting algorithms, including their implementation and performance and visualization.

Bubble Sort

Bubble sort is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order.

In my understanding it just a sorting funtions that drags the larger elements to the end of the list.

It is easy to understand and implement compared to most other algorithms.

Implementation

Here is a simple implementation of bubble sort in C:

                    
void bubble_sort(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // swap arr[j] and arr[j + 1]
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

Bubble sort can be optimized by stopping the algorithm if the inner loop doesn't make any swaps (because it is already sorted).
